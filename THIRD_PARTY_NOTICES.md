# Dependencies and provenance

The source and binary include:

- **Dear ImGui v1.91.9b**, commit `f5befd2d29e66809cd1110a152e375a7f1981f06`. Copyright Omar Cornut and contributors, MIT. Source: https://github.com/ocornut/imgui. Full license: `licenses/imgui-LICENSE.txt`. Official Win32 and DX12 backends are unmodified.
- **MinHook v1.3.4**, commit `c3fcafdc10146beb5919319d0683e44e3c30d537`. Copyright Tsuda Kageyu and contributors, BSD-style license including HDE notices. Source: https://github.com/TsudaKageyu/minhook. Full notices: `licenses/minhook-LICENSE.txt`.
- **TarnishedTool source facts, adapted behavior and generated item catalog**, commit `2a7a76939d3dd21c233ee4f1e5df3b2dddf0e49c`. Copyright (c) [2025] [Shilkey], MIT. Source: https://github.com/borgCode/TarnishedTool. Full license: `licenses/TarnishedTool-LICENSE.txt`. Relevant snapshots under `provenance/` are unmodified, including `Resources.resx` with upstream item CSV resources and assembly calling conventions. The filtered catalog is generated by `GenerateCatalog.py`.

The local MSYS2 GCC 14.2.0 compiler statically links its runtime under the GCC Runtime Library Exception. MinGW-w64 supplies Windows headers and import libraries. System DirectX, Windows APIs and Segoe UI are used from the user's installation; no game binaries, save files, game artwork or system fonts are redistributed.

Original toolkit code is MIT licensed; see `LICENSE.txt`. The existing mod loader, Elden Menu, and offline launcher remain separately installed software and are not included in the toolkit distribution. Research clones are not needed to build and are not shipped in the distribution archive.

Weapon base/DLC classification is corroborated using factual numeric ID membership from [Erd-Tools](https://github.com/Nordgaren/Erd-Tools), commit `a2757f930afa3109dc4816d3f04e7cd11b91fea1`. `provenance/weapon-content.json` lists paths, hashes and numeric memberships; no implementation or item descriptions from that repository are redistributed. Weapon names and grant IDs remain from the MIT TarnishedTool snapshot above.

The additional unmodified `provenance/Offsets-2.7.1.cs` snapshot is from MIT TarnishedTool commit `8df23f1b19c62997ba9e3822495c1d2bd001ab88` (patch 1.17.1 support); the same TarnishedTool license above applies. The original catalog and behavior snapshots remain pinned to their earlier commit.

Horse-jump instruction-site research used the Hexinton table at commit `e2c2d20ad92542d46dce41c9faf183dbd6f18f3d` (https://github.com/Hexinton/eldenringcheatengine). Only factual instruction signatures and addresses, corroborated against the installed executable, are recorded in `provenance/horse-jump-2.7.1.json`. No trainer implementation or archive is redistributed. The conditional assembly hooks and native fixture are original toolkit code; the already bundled MinHook library handles detours.
